### 1. 理化学研究所 基礎科学特別研究員制度（SPDR）

自由な発想で主体的に研究できる場を理研において提供する制度です。自らの研究提案に基づく研究を高い自主性のもとで遂行できるよう手厚い支援（3年任期、給与および年間約100万円の研究費）が受けられます。

* **応募資格:** 博士号取得後5年未満の研究者（出産・育児等による休業期間の延長措置あり）。
* **スケジュール:** 毎年 **2月上旬に公募開始、4月上旬に登録・申請締切**（翌年4月着任）。
* **応募方法:** 事前に受入研究者との綿密な研究打ち合わせが必須となるため、当研究室での応募を希望される方は **公募直前の12月～1月頃** までに履歴書と研究構想をご連絡ください。

理研 SPDR 公式ページ:  
<a href="https://www.riken.jp/careers/programs/spdr/" target="_blank" rel="noopener noreferrer">https://www.riken.jp/careers/programs/spdr/</a>

### 2. 杉田研における JSPS 外国人特別研究員の内部選考（事前審査制度）

<div style="background-color: #f0f7ff; border: 1px solid #d0e2ff; padding: 16px 20px; margin: 20px 0; border-radius: 4px;">
  <p style="margin: 0 0 10px 0; font-weight: bold; color: #0043ce; font-size: 1.05em;">
    なぜ研究室内の事前審査が必要なのか
  </p>
  <p style="margin: 0; line-height: 1.6;">
    日本学術振興会（JSPS）の公式規程により、<strong>日本の受入研究者が1回の募集期に推薦できる候補者は最大3名まで</strong>と厳格に制限されており、複数の候補者を推薦する場合は受入研究者が<strong>優先順位（1位・2位・3位）</strong>を付して申請しなければなりません。また、理研の機関内締切はJSPS公式締切の約1ヶ月前に設定されています。このため、当研究室では申請書の質を最大限に高め、公平に選抜を行うための「研究室内事前審査」を実施しています。
  </p>
</div>

#### 事前審査の申請方法
杉田研を受入先として JSPS 外国人特別研究員（一般・長期または短期）への応募を希望する方は、<strong>理研内締切の4週間前まで</strong>（春募集の場合は例年2月下旬、秋募集の場合は例年6月下旬）に、以下の審査書類一式をメールにてお送りください：

* **書類1：学術履歴書（CV、英文）**
  - 学歴、学位取得（予定）日、詳細な論文業績リスト（筆頭著者・責任著者の区別を明記）、シミュレーションや開発に関するスキル要約。
* **書類2：研究構想書 / プロポーザル骨子（1～2ページ、英文）**
  - 取り組みたい物理・生物学的課題と、<strong>なぜ杉田研が受入先として最適なのか（当研究室のツール・強み・研究テーマとの親和性）</strong>を明記してください。
* **書類3：代表的な論文（PDF）**
  - 自身が筆頭著者の主要論文またはプレプリント（最大2編）。
* **書類4：推薦者2名の連絡先**
  - 指導教員を含む推薦者2名の氏名・所属・メールアドレス。

#### 選考と推薦のプロセス
1. **書類審査:** 研究業績、研究計画の独創性、当研究室のプロジェクトとのシナジーを総合的に審査します。
2. **オンライン面談:** 有望な候補者には、30分程度のオンライン面談（研究プレゼンおよびディスカッション）を実施します。
3. **受入決定と共同推敲:** 最大3名の候補者を正式に決定・順位付けし、採択に向けた本申請書を数週間かけて主宰者と共同で徹底的に推敲・作成します。

JSPS 外国人特別研究員制度公式ページ:  
<a href="https://www.jsps.go.jp/j-fellow/" target="_blank" rel="noopener noreferrer">https://www.jsps.go.jp/j-fellow/</a>

### 3. 研究室プロジェクト直接雇用について

現在、研究室の直接雇用枠（研究員・ポスドク等）の公募は行っておりません。新規プロジェクトの採択等に伴い直接雇用の枠が発生した場合は、理研の採用情報ページおよび当ウェブサイトにて速やかに公募情報を掲載いたします。

### 4. 日本学術振興会 特別研究員制度（PD・RPD、理研雇用型）

日本国籍または永住権を持つ研究者（もしくは日本の大学で学位を取得した研究者）を主な対象とし、理研の任期制職員として雇用されながら研究を行います。
* **募集時期:** 例年4月～5月頃。
* **応募方法:** 3月中に研究室主宰者の受諾と所内手続きを完了させる必要があるため、早めにご相談ください。

JSPS 特別研究員（PD）公式ページ:  
<a href="https://www.jsps.go.jp/j-pd/" target="_blank" rel="noopener noreferrer">https://www.jsps.go.jp/j-pd/</a>

### 当研究室が注力する研究領域と期待される専門性

研究提案の作成にあたっては、以下の当研究室の主要テーマとの協調性・発展性を考慮されることを強く推奨します：

1. **高性能分子動力学計算ソフトウェアおよびアルゴリズム開発:** 超並列計算・GPU最適化、拡張アンサンブル法、自由エネルギー計算手法の開発（[GENESIS](https://www.r-ccs.riken.jp/labs/cbrt/) を中心とした開発）。
2. **生体分子凝集体と相分離（LLPS）:** 天然変性タンパク質（IDP）やタンパク質-RNA複合体の相分離メカニズムに関するマルチスケール（全原子～粗視化）シミュレーション。
3. **クライオ電子顕微鏡・トモグラフィー（Cryo-EM/ET）フレキシブルフィッティング:** 低・中解像度密度マップからの構造モデリングおよび構造ダイナミクス解析。
4. **酵素反応機構とマルチスケール QM/MM 計算:** 機械学習ポテンシャル（ML/MM）を用いた酵素反応経路や超分子複合体の機能解析。
